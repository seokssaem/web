빅데이터 분석 플랫폼
개발자 양성과정

본 과정은 NCS 16개 능력단위를 6개의 Phase로 재구성하여 24주간 진행됩니다. 환경 세팅부터 데이터 엔지니어링, 분석·AI, 플랫폼 개발, 그리고 포트폴리오 완성까지 — 아래 시간표와 커리큘럼을 바탕으로 함께 학습하게 될 여정입니다. 매 Phase의 다짐을 마음에 새기며 5개월을 끝까지 완주합시다.

완충 구간
01 / 강의 순서

5개월 주차별 학습 계획

각 Phase는 학습 목표에 따라 명확히 구분됩니다. 완충 구간(🔥)은 그동안의 학습을 점검하고 호흡을 가다듬는 발표·시연 주간입니다.

Phase
01
생존 구간
WEEK 1 — 3

환경 세팅과 웹 기초를 선행 투입하여 수강생의 초기 불안을 해소하고 학습 리듬을 만든다.

01

개발자 환경 구축

NCS 2001020233_23v5Lv.2

Python / Git / VS Code / JupyterLab 설치, 가상환경 구성, GitHub 연동까지.

02

응용SW 기초 기술 활용

NCS 2001020232_23v5Lv.3

Linux 기초, 네트워크·SQL·MySQL 기초, 클라우드 개요.

03

프로그래밍 언어 응용

NCS 2001020230_23v5Lv.3

Python 심화, 파일 I/O, requests, BeautifulSoup 크롤링 기초. ⭐ 비NCS 선행 — HTML/CSS 기초, Grid/Flexbox, 미디어쿼리 반응형, Chart.js 시각화 연동. ⭐ 미니 프로젝트 시작 — 개인 데이터 수집 & 시각화 페이지 제작.

학생 다짐 모르는 것이 많아도 도망치지 않겠습니다. 환경 세팅에서 막혀도 끝까지 해결하고, 매일 조금씩이라도 코드를 직접 쳐 보겠습니다. HTML/CSS와 미니 프로젝트는 앞으로의 모든 수업의 기초가 되므로 가볍게 여기지 않겠습니다.
Phase
02
설계 구간
WEEK 4 — 5

요구사항 분석과 아키텍처 설계로 팀 프로젝트를 본격적으로 시작한다.

04

빅데이터 플랫폼 요구사항 분석

NCS 2001020901_24v3Lv.7

팀 주제 선정·역할 분담, 공공데이터 포털 탐색, 요구사항 정의, Git 협업·형상관리, JupyterLab 환경 설정.

05

빅데이터 플랫폼 아키텍처 설계

NCS 2001020902_24v3Lv.6

데이터 흐름 정의, Lambda / Kappa 아키텍처 이해, 기술스택 선정, 아키텍처 문서화.

학생 다짐 팀의 일은 곧 나의 일이라 생각하겠습니다. 역할을 회피하지 않고 책임지며, Git 충돌이 생겨도 침착하게 해결하겠습니다. 동료의 코드를 존중하고, 의견이 다를 땐 감정이 아닌 근거로 이야기하겠습니다.
Phase
03
데이터 엔지니어링
WEEK 6 — 10

수집 → 저장 → 처리 → 전처리에 이르는 데이터 파이프라인을 구성한다.

06

빅데이터 수집시스템 개발

NCS 2001020903_24v3Lv.4

OpenAPI 연동, requests · BeautifulSoup 크롤링 심화, CSV · Excel(openpyxl) 처리, 수집 자동화.

07

빅데이터 저장시스템 개발

NCS 2001020904_24v3Lv.4

MySQL 정형 데이터 저장 심화, Hadoop(HDFS) 대용량 저장, 데이터 레이크 구성.

08

빅데이터 처리시스템 개발

NCS 2001020905_24v3Lv.5

Pandas · NumPy 결측치·이상치 처리, 데이터 정규화·변환·필터링 자동화, Spark 기초.

09

분석 데이터 전처리

NCS 2001010510_21v4Lv.5

전처리 자동화 심화, 프로젝트 데이터셋 생성 및 정제 관리, 정제된 데이터셋 완성.

🔥 완충 구간 / 중간 발표 수집~전처리 결과를 팀별로 발표하고 피드백 및 방향을 점검합니다.
학생 다짐 가장 힘든 구간임을 인정하고, 결과가 더디더라도 포기하지 않겠습니다. 데이터 한 줄 한 줄을 정성껏 다루며, 중간 발표는 부담이 아닌 점검의 기회로 받아들이겠습니다.
Phase
04

EDA → 모델링 → 분석시스템 구현으로 데이터에서 인사이트와 의사결정을 도출한다.

10

NCS 2001010511_21v4Lv.6

Seaborn · Plotly · Matplotlib EDA 시각화, 데이터 패턴·분포 탐색, 인사이트 도출.

11

빅데이터 분석 모델링

NCS 2001010513_21v1Lv.7

회귀·분류·클러스터링 모델 (scikit-learn, XGBoost), 의사결정 시나리오 작성.

12

빅데이터 분석시스템 개발

NCS 2001020906_24v3Lv.5

분석 코드 구조화, 자동화 프로세스 반영, 분석시스템 구현.

🔥 완충 구간 / Demo Day 분석 결과를 시연하고, 모델 성능을 발표하며, 중간 포트폴리오를 점검합니다.
학생 다짐 모델의 정확도에 일희일비하지 않고, 왜 그런 결과가 나왔는지 끝까지 묻겠습니다. Demo Day는 자랑이 아닌 배움의 자리이며, 동료의 발표에서도 진심으로 배우겠습니다.
Phase

시각화 → 서버 → 통합 구현으로 분석 결과를 플랫폼 형태로 완성한다.

통합 구현

NCS 2001020206_23v6Lv.5

Streamlit 분석 대시보드, HTML · CSS 프론트엔드 커스터마이징, 웹 기반 통합 시각화·UI, 전체 파이프라인 통합, 최종 보고서·발표자료(PPT · PDF) 작성.

학생 다짐 지금까지 배운 모든 것을 하나의 플랫폼으로 연결하겠습니다. ‘되긴 되는데’에 만족하지 않고, 사용자 입장에서 한 번 더 다듬겠습니다. 마지막 통합 단계에서 가장 큰 성장이 일어남을 잊지 않겠습니다.
Phase
06
취업 완성
WEEK 21 — 24

테스트 + 포트폴리오 + 최종 발표로 과정을 마무리하고 취업을 준비한다.

16

빅데이터 플랫폼 테스트

NCS 2001020908_24v3Lv.3

단위·통합·성능 테스트, 결함 분석, 아키텍처·데이터 흐름 문서화, Streamlit · Flask · API 구현 결과 포트폴리오 제작, 팀별 최종 발표, 피드백·개선사항 반영.

학생 다짐 이제는 스스로 묻고 스스로 답하는 개발자가 되겠습니다. 포트폴리오는 누구에게 보여주기 위함이 아니라, 5개월간의 나를 증명하는 기록입니다. 마지막 발표까지 한 사람도 남김없이 함께 완주하겠습니다.
02 / 학습 약속

우리가 함께 지킬 세 가지 약속

5개월의 여정을 끝까지 완주하기 위해 우리 모두가 함께 지킬 약속입니다. 이 약속이 우리를 끝까지 데려다 줄 것입니다.

PROMISE 01
기초를 가볍게 여기지 않겠습니다
HTML·CSS·Python·Git처럼 단순해 보이는 기초가 결국 Chart.js, Flask, Streamlit으로 이어집니다. 빨리 가려 하지 않고 정확히 가겠습니다.
PROMISE 02
매주 작은 결과물을 남기겠습니다
완벽한 결과보다 꾸준한 기록을 우선합니다. 미니 프로젝트와 매주의 커밋이 모여 5개월 뒤 나의 포트폴리오가 됩니다.
PROMISE 03
동료와 함께 끝까지 완주하겠습니다
혼자 빨리 가는 것보다 함께 끝까지 가는 것이 더 멀리 갑니다. 묻기를 부끄러워하지 않고, 답하기를 아끼지 않겠습니다.
