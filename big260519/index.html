강의 영상

영상은 수업 진행 순서대로 배치했습니다. 각 카드에는 전사본을 바탕으로 확인한 SQL 마무리와 HTML 실습 포인트를 함께 정리했습니다.

복습 흐름

SQL 문법의 우선순위를 정리한 뒤, HTML 문서 기본 구조와 시맨틱 레이아웃, 텍스트 태그, 목록, 표 순서로 복습하세요.

  1. 1
    SQL 마무리 SELECT, DML, DDL을 구분하고 CREATE, ALTER, DROP 같은 구조 관리 문법의 위치를 잡습니다.
  2. 2
    웹 기본 개념 HTML은 구조, CSS는 디자인, JavaScript는 동작을 맡는다는 역할 구분을 확인합니다.
  3. 3
    HTML 문서 구조 doctype, html, head, body, meta, title, h1, p, hr을 직접 작성하며 문서의 뼈대를 만듭니다.
  4. 4
    시맨틱 태그와 표 header, nav, main, section, footer, 목록 태그, table, rowspan, colspan, colgroup을 실습합니다.

체크리스트

체크 상태는 현재 브라우저에 저장됩니다.

수업 메모

원본 영상 전사 내용을 바탕으로 SQL 마무리와 HTML 실습 흐름을 다시 정리한 요약입니다.

오늘의 큰 흐름

오늘은 SQLBolt에서 배운 SELECT 중심 문법을 정리하고, DML과 DDL의 차이를 확인한 뒤 HTML/CSS 웹 기초로 넘어갔습니다. 후반부에는 VS Code와 Live Server로 HTML 문서를 직접 만들며 구조 태그를 실습했습니다.

중요한 실습 포인트

핵심은 HTML을 단순히 화면에 보이는 글자가 아니라, 브라우저와 검색 엔진, 보조 기술이 읽는 문서 구조로 보는 것입니다. 그래서 lang, meta charset, title, 시맨틱 태그, alt와 같은 정보가 중요하게 다뤄졌습니다.

복습 시 주의할 점

오늘 HTML 실습은 태그 이름을 외우는 것보다 문서의 어느 영역을 어떤 태그로 감싸는지 이해하는 쪽이 중요합니다. 특히 id는 한 번 쓰는 이름, class는 여러 곳에 반복해서 쓰는 이름이라는 감각을 잡아두면 CSS 수업으로 이어가기 쉽습니다.
