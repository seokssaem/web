  3. 3

오늘의 큰 흐름

오늘은 오전에 클래스 변수와 클래스 메서드를 되짚은 뒤, Animal, Dog, Cat 예제로 상속의 기본 구조를 확인했습니다. 이어서 Parent/Child와 Car/Hybrid 예제로 부모 기능을 재사용하고 자식 기능을 확장하는 흐름을 다뤘고, 오후에는 CSS 그라디언트와 반응형 웹 개념으로 넘어갔습니다.
