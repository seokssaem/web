03   공공데이터포털 xpos / ypos 주의
⚠ CAUTION — xpos와 ypos 순서

공공데이터포털 버스 API 응답에서 xpos는 경도(longitude), ypos는 위도(latitude)야.
수학 좌표계 기준(x=가로=동서, y=세로=남북)이라서 일반 지도 API와 순서가 반대야.
Folium, Kakao Map 등에 넣을 때는 반드시 lat=float(ypos), lon=float(xpos)로 바꿔야 해.

📌 빠른 구분법 (한국 기준)

값이 35~38 사이면 → 위도(latitude)   |   값이 126~130 사이면 → 경도(longitude)
숫자 크기만 봐도 바로 판별 가능. API 문서를 못 찾을 때 유용해.

04   Python 코드 예제
daegu_bus_map.py 
# 대구 버스 정류장 좌표 → Folium 지도 실습
import folium

# 대구 중심부 기준 좌표
DAEGU_LAT = 35.8714   # 위도 (ypos)
DAEGU_LON = 128.6014  # 경도 (xpos)

# 지도 생성 — location은 [위도, 경도] 순서!
m = folium.Map(location=[DAEGU_LAT, DAEGU_LON], zoom_start=13)

# 공공데이터포털 API 응답 예시 (버스 정류장)
stations = [
    {"name": "동성로",      "xpos": "128.6014", "ypos": "35.8714"},
    {"name": "대구역",      "xpos": "128.6267", "ypos": "35.8786"},
    {"name": "경북대학교",  "xpos": "128.6100", "ypos": "35.8890"},
    {"name": "수성못",      "xpos": "128.6379", "ypos": "35.8513"},
]

for s in stations:
    # ⚠ xpos → 경도(lon), ypos → 위도(lat) 순서 주의!
    lat = float(s["ypos"])  # ypos = 위도
    lon = float(s["xpos"])  # xpos = 경도

    folium.Marker(
        location=[lat, lon],
        popup=s["name"],
        tooltip=s["name"],
    ).add_to(m)

m.save("daegu_bus.html")
print("저장 완료: daegu_bus.html")

folium.PolyLine([(lat1,lon1),(lat2,lon2), ...]) 으로 버스 경로 시각화

07   심화 — PolyLine 노선 경로 그리기
daegu_bus_route.py 
import folium

m = folium.Map(location=[35.8714, 128.6014], zoom_start=13)

# 527번 버스 정류장 (위도, 경도) 리스트
route_527 = [
    (35.8799, 128.6285),  # 동대구역
    (35.8786, 128.6267),  # 대구역
    (35.8714, 128.6014),  # 동성로
    (35.8687, 128.5930),  # 서구 방면
]

# 노선 경로 그리기
folium.PolyLine(
    route_527,
    color="#1a6fd4",
    weight=4,
    opacity=0.8,
    tooltip="527번 버스"
).add_to(m)

# 각 정류장 마커
for i, (lat, lon) in enumerate(route_527):
    folium.CircleMarker(
        location=[lat, lon],
        radius=6,
        color="#1a6fd4",
        fill=True,
        popup=f"정류장 {i+1}"
    ).add_to(m)

m.save("daegu_route_527.html")
