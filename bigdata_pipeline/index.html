발견한 문제들

기상청 좌표가 위경도가 아닌 격자 (nx, ny) → 변환 필요

🔴

import pandas as pd

# 결측값 처리 ("-" → NaN)

NCS 과정에서 구현

DB에 쌓인 데이터를 외부에 제공하는 REST API를 FastAPI로 만듭니다.

from fastapi import FastAPI
import psycopg2

app = FastAPI()

@app.get("/stops/{stop_id}/context")
async def get_stop_context(stop_id: str):
  # DB에서 정류장 + 날씨 + 대기 + 주변병원 한번에 조회
  return {
    "stop": get_stop(stop_id),
    "weather": get_latest_weather(),
    "air_quality": get_air(stop_id),
    "nearby_hospitals": get_nearby(stop_id, radius=500)
  }
